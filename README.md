🦁 CYBER LION SECURITY TOOLKIT

Ultimate Defensive Cybersecurity Toolkit

Created by GOKU (Rizvi)

CYBER LION is an educational cybersecurity project featuring defensive security tools and utilities.

🚀 Features

- URL Security Analyzer
- HTTPS Checker
- Suspicious URL Pattern Checker
- Email Validator
- Password Strength Analyzer
- Password Generator
- SHA256 Hash Generator
- File Integrity Checker
- File Metadata Viewer
- Duplicate File Finder
- JSON Validator
- Base64 Encoder & Decoder
- DNS Lookup
- IP Information
- Internet Connectivity Checker
- TLS Certificate Viewer
- Local Network Information
- Security Checklist
- UUID Generator
- Security Report Generator
- And more!

💻 Requirements

- Python 3
- Termux or Linux
- Git

⚙️ Installation

git clone https://github.com/gokusPain09-bit/CYBER-LION-SECURITY-TOOLKIT.git

cd CYBER-LION-SECURITY-TOOLKIT

python security_toolkit.py

📱 Supported Platforms

- Android (Termux)
- Linux
- Python environments

🛡️ Purpose

This project is designed for defensive cybersecurity education and authorized security testing.

Use responsibly and only on systems you own or have permission to test.
