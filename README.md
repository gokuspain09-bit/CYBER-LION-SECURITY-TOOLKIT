🚀 ABOUT PROJECT

CYBER LION SECURITY TOOLKIT is an educational cybersecurity project featuring defensive security tools, network utilities, file analysis tools and security checkers.

Designed for cybersecurity learners, developers and authorized security testing.

⚡ FEATURES

- URL Security Analyzer
- HTTPS Checker
- Suspicious URL Pattern Checker
- Email Validator
- Password Strength Analyzer
- Password Generator
- SHA256 Hash Generator
- File Integrity Checker
- File Metadata Viewer
- Duplicate File Finder
- JSON Validator
- Base64 Encoder & Decoder
- DNS Lookup
- IP Information
- Internet Connectivity Checker
- TLS Certificate Viewer
- Local Network Information
- Security Checklist
- UUID Generator
- Security Report Generator
- And more!

🛠️ TERMUX INSTALLATION

Step 1 — Install Termux

Install Termux from its official source:

https://github.com/termux/termux-app

Step 2 — Update Termux

pkg update && pkg upgrade -y

Step 3 — Install Required Packages

pkg install python git -y

Step 4 — Clone Repository

git clone https://github.com/gokusPain09-bit/CYBER-LION-SECURITY-TOOLKIT.git

Step 5 — Open Project Folder

cd CYBER-LION-SECURITY-TOOLKIT

Step 6 — Run Toolkit

python security_toolkit.py

🦁 CYBER LION SECURITY TOOLKIT is ready!

---

🔄 UPDATE TOOLKIT

To download the latest repository changes:

cd CYBER-LION-SECURITY-TOOLKIT
git pull

Then run:

python security_toolkit.py

🔁 RUN AGAIN

Whenever you want to start the toolkit:

cd CYBER-LION-SECURITY-TOOLKIT
python security_toolkit.py

🐛 TROUBLESHOOTING

Python not found:

pkg install python -y

Git not found:

pkg install git -y

Project folder not found:

ls

Check Python version:

python --version

Check project files:

ls -la
